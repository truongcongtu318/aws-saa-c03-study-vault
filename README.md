## 💡 Cách sử dụng hiệu quả

### 1. Mở bằng Obsidian (Khuyên dùng)
- Tải và cài đặt [Obsidian](https://obsidian.md/).
- Chọn **"Open folder as vault"** và trỏ đến thư mục `D:\xbrain\saa`.
- Mở file `00-Index/00-Domain-1-MOC.md` để bắt đầu.
- Sử dụng tính năng **Graph View (`Ctrl + G`)** để xem mạng lưới liên kết giữa các dịch vụ AWS.
- Bấm vào các liên kết `[[Tên-Ghi-Chú]]` để điều hướng nhanh.

### 2. Xem trực tiếp trên GitHub hoặc VS Code
- Mọi ghi chú đều được định dạng chuẩn **CommonMark**.
- Bảng biểu so sánh và sơ đồ trực quan **Mermaid.js** hiển thị tự nhiên.
